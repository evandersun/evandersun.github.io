怎么添加

  • Sileo：源 → ＋ → 粘贴地址 → 添加源
  • Zebra：Sources → Add → 粘贴地址
  • Cydia：源 → 编辑 → 添加 → 输入地址
  • Installer：Sources → ＋ → 粘贴地址

添加后搜索 ScreenTimeSpoofer 安装即可。

包会自动匹配架构

源里同时提供两个包，包管理器按设备架构自动选对那个，不用手动挑：
