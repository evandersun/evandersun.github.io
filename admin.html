关于存储：文件保存在网站仓库的 uploads/ 目录，并登记在公开的 uploads/manifest.json 里，因此任何设备（手机/电脑）打开本页都能看到并下载，不需要填令牌；只有上传、删除需要令牌。登录并连接令牌后，每行「下载」后面会出现「删除」按钮，点它会先二次确认，再同时移除仓库里的文件和清单记录（一次提交完成）。
上传后：GitHub Pages 通常需要 10–60 秒发布新文件，若在别的设备上还看不到，稍等后点「刷新列表」即可。
含密钥的文件：检测到疑似密钥（ghp_...、github_pat_...、私钥、AKIA... 等）时不会明文入库，本页会自动压缩存储并标注「压缩存储」，点「下载」时在浏览器里还原成原文件；若服务器仍以「Secret detected」拒绝，也会自动回退到压缩存储。
上传插件：zip 文件名是插件名，包内固定 arm64.deb（rootless）和 arm64e.deb（roothide）。网页在本机解压、读取 deb 的 control，自动重建 Packages / Packages.gz / Release，两个 deb 存进 debs/、原 zip 存进 zips/，一次提交完成，不需要服务器，上传完就直接进源。删除插件同样会自动重建索引。
已收录插件：这张表读的是源里的 Packages 索引，所以列出来的就是包管理器里能装到的；不用令牌（如手机）也能看到，只是不能删除。
下载加速：20MB 以内的文件会优先从 jsDelivr 加速节点取回，实测比 GitHub Pages 快一个数量级，下载时显示实时进度；节点不通会自动回退本站。两种情况下没有加速：超过 20MB（加速节点有单文件上限），以及 Office 文档（xlsx / docx / pptx，被 jsDelivr 直接 403 屏蔽）——这两种会在列表里标「无加速」，走本站会慢一些；Office 文件可以先压成 zip 再上传，就能享受加速。
限制：单文件上限 40MB（GitHub 写入接口实测可传 40MB，45MB 起会被拒绝）；同名文件会覆盖旧版本。请一次上传一个插件 zip，避免并发提交冲突。
安全：本页密码是前端简易门禁，不是服务器级防护；令牌仅存于本机浏览器，请勿在公用设备上勾选「记住」。
